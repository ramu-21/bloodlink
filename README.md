# 🩸 BloodLink – Blood Bank Management System

BloodLink is a simple **C++ console-based Blood Bank Management System**.
It helps manage donor details and keep track of available blood units.

This project was created to practice basic C++ programming concepts such as arrays, structures, functions, loops, conditions, and user input.

## ✨ Features

* Add donor details
* View all donors
* Find donors by blood group
* Add available blood units
* View available blood
* Give blood when requested
* Simple menu-based system

## 🛠️ Technologies Used

* C++
* C++ Standard Library
* Console / Terminal

## 📚 Concepts Used

* `struct`
* Arrays
* Functions
* Loops
* `if-else`
* `switch`
* Strings
* User input and output

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/BloodLink.git
```

2. Open the project in VS Code or any C++ IDE.

3. Compile the program:

```bash
g++ main.cpp -o BloodLink
```

4. Run it:

```bash
./BloodLink
```

On Windows, you can run:

```bash
BloodLink.exe
```

## 📌 Project Status

This is the **first simple version** of BloodLink. More features can be added in the future, such as saving data to files, emergency blood requests, blood matching, and expiry-date tracking.
